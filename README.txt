BREW HAVEN COFFEE SHOP WEBSITE

Pages:
- index.html - Store Homepage
- shop.html - Shop/Menu; products are generated with a JavaScript loop
- cart.html - Shopping Cart
- checkout.html - Shipping + purchase forms, validation, coupon discounts
- confirmation.html - Order Confirmation
- contact.html - Contact form

Other files:
- styles.css - external stylesheet
- script.js - product loop, cart, validation, coupon discount functions
- images/ - product images

JavaScript product requirement:
The Shop/Menu page stores 10 products in a JavaScript array and uses forEach() to create each responsive product card.

Coupon codes for the demo:
- BREW10 = 10% off total
- COFFEE15 = 15% off total

Form validation:
Checkout checks required fields, ZIP, phone, state, credit card number, security code, and expiration date.
Contact checks required email and message and validates email format.

IMPORTANT: This is a student demonstration site. Do not enter real payment card information.
